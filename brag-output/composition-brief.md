# Composition brief

Make the 22-second landscape tour in `brag-plan.md` using HyperFrames and one
paused, seekable GSAP timeline. The circuit diagram is the same subject as the
README artwork. Preserve the navy, ice, blue and copper identity. Use local
dependencies and system fonts; do not fetch assets during rendering.

The token means supported wrapped rendering, not every installed app. The
internal panel and explicit synchronization remain on iGPU. D3cold is the
observed target result, illustrated without a countdown or latency claim.

Output: `brag.mp4` and a settled `brag.jpg` poster, with the poster baked into
frame zero. Keep the HTML and the locally synthesized WAV source reproducible.
No narration or external publishing from the video tool. The finished video is
included in the GitHub repository requested by the owner.

Validate runtime, layout, motion, and contrast with `hyperframes check`, inspect
key frames, open the local preview, then render. The user's request includes
the completed video in the published repository.
